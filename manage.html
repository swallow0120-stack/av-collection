如何發布到正式網站？
  1. 點「匯出更新檔」，取得 catalog.json。
  2. 開啟 GitHub 資料資料夾，選 Add file → Upload files，上傳剛下載的檔案。
  3. 確認檔名是 catalog.json，按 Commit changes。網站會自動驗證及更新。
  4. 等待 Actions 顯示成功，再重新整理收藏網站。若驗證失敗，查看錯誤後修正資料。

匯出的檔案也可作為備份；下次可使用「匯入草稿」繼續編輯。
